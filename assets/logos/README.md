ارفع لوجوهات العملاء في الفولدر ده.
Upload the client logos into this folder.

> **ليه الفولدر فيه الملف ده؟** Git مبيحفظش الفولدرات الفاضية — الملف ده بيخلي

> **Why this file exists:** Git cannot track an empty directory, so this file
> holds the folder open until the logos land. Don't delete it before uploading.

## المواصفات / Format

- **PNG بخلفية شفافة** أو SVG — الأفضل. خلفية بيضا برضه شغالة، الشريط أبيض.
- ارتفاع **200px** على الأقل.
- اللوجو لازم يكون غامق أو ملون — الشريط خلفيته بيضا، فنسخة أبيض بس مش هتبان.
- لو اللوجو فيه اسم البراند مكتوب جواه (زي اللي بعتّهم)، النص اللي جنبه في الصفحة
  هيتشال عشان الاسم مايتكررش.

Transparent PNG or SVG preferred; 200px tall minimum; dark or coloured artwork
(the strip sits on white, so a white-only version will not show). Where the
lockup already contains the brand name, the adjacent text in the page is
dropped so the name is not repeated.
